# Liquee — поддержка и конфиденциальность

Публичные страницы для пользователей Liquee и карточки App Store.

- Поддержка: https://bliinmaker.github.io/liquee-support/
- Конфиденциальность: https://bliinmaker.github.io/liquee-support/privacy.html
- Контакт: kinozemts@gmail.com

В этом репозитории только статические веб-страницы. Исходников приложения и пользовательских данных нет.

## Проверка

python3 -m http.server 8769

Страницы должны возвращать HTTP 200; локальные ссылки и ресурсы должны открываться и при публикации под префиксом /liquee-support/.
